The Form Element

A <form> groups controls for submission. action specifies the destination and method specifies how the browser sends values. Each submitted control needs a name.

GET appends named values to the URL and is useful for searches. POST sends values in the request body and is commonly used for account or private form submissions. A real destination is needed to process either request.

<form action="/submit" method="POST">
  <input name="username" type="text">
  <button type="submit">Submit</button>
</form>
