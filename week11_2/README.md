# Week 11_2 — React ProductCard

A separate React Code Challenge project for building a reusable `ProductCard`
component. It accepts a product name, KRW price, 0–5 rating, and stock status.

## Run locally

```bash
npm install
npm start
```

## Test and build

```bash
npm test -- --watchAll=false
npm run build
```

`src/ProductCard.js` contains the reusable component. `src/App.js` demonstrates
the professor's Wireless Earbuds example and a second product that is out of
stock.
